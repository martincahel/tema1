# Citace

## Použité prompty

- „vygeneruj mi web na tema anticke recko“
- „všechny stránky obsahují odkazy na validaci html a css.“
- „všechny stránky obsahují odkaz na soubor s citacemi a zdroji.“
- „dej zdroj a citaci zvalst, citace at je md“
- „tou citaci nemyslim nejake citaty, ale priznani co si stvoril ty jako ai a ja jako clovek“
- „bude se to jmenovat stejne citace divej tady mas ukazku jak to ma vypadat“

## Poznámka k autorství

Web vytvořil AI asistent s Copilot SDK ve VS Code podle zadání a pokynů člověka. AI připravila
texty, strukturu stránek a zdrojový kód HTML, CSS a JavaScriptu. Člověk určil téma a požadavky
a rozhoduje o kontrole, úpravách a zveřejnění výsledku. Ilustrace chrámu je vytvořená jako SVG
přímo v projektu; externě se načítají písma Google Fonts.
